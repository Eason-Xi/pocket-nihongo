# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

| File | Size and format | Use and source |
| --- | --- | --- |
| [`fonts/jp_font_14.c`](fonts/jp_font_14.c) | 14 px, 4 bpp LVGL `lv_font_fmt_txt`, 626 glyphs | Pocket Nihongo hints, battery, and small labels. Subset of Source Han Sans CN Regular 2.005 (SIL OFL 1.1). |
| [`fonts/jp_font_20.c`](fonts/jp_font_20.c) | 20 px, 4 bpp, 626 glyphs | Pocket Nihongo titles, menu rows, readings, and meanings. Same source as above. |
| [`fonts/jp_font_32.c`](fonts/jp_font_32.c) | 32 px, 4 bpp, 626 glyphs | Pocket Nihongo word faces, romaji, and result stamp. Subset of Noto Sans CJK JP Regular 2.004 (SIL OFL 1.1), so kanji use Japanese glyph forms. |
| [`fonts/jp_font_72.c`](fonts/jp_font_72.c) | 72 px, 4 bpp, 148 glyphs | Pocket Nihongo kana cards: only the hiragana and katakana used by the kana decks. Same source as the 32 px font. |

The Pocket Nihongo fonts are generated by `tools/jp_learner/gen_fonts.py` with Pillow/FreeType (no `lv_font_conv`). The character set is extracted from `main/jp_text.h` and `tools/jp_learner/jp_content.py`; `tests/test_jp_font_coverage.py` fails when a string or content change is not followed by a regeneration. The source OTF files are not committed. The generated subsets do not use the reserved font names, and redistribution follows the SIL Open Font License 1.1.

## Images

Store reusable source images and generated display assets in `images/`.

| File | Dimensions and format | Use and source |
| --- | --- | --- |
| [`images/home.jpg`](images/home.jpg) | 3840 × 2160, JPEG | Product hero image embedded in both project README files to foreground AI Passport and its open, maker-oriented identity. |
| [`images/readme-hardware-specs.png`](images/readme-hardware-specs.png) | 2172 × 724, PNG RGBA | Optional technical infographic retained as a reference asset; it is no longer used as the homepage hero. | [`images/logo-wordmark.png`](images/logo-wordmark.png) | 1648 × 336, PNG RGBA | Transparent black wordmark extracted from the repository's original `images/logo.png`; embedded in both project README files for light backgrounds. |
| [`images/logo-wordmark-dark.png`](images/logo-wordmark-dark.png) | 1648 × 336, PNG RGBA | White version of the extracted wordmark, used by the README `<picture>` element when GitHub is in dark mode. |

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

| File | Format | Use and source |
| --- | --- | --- |
| `music/jp_voice_pack.bin` | 16 kHz mono IMA-ADPCM (4 bit), 257 clips, 145.5 s, about 1.14 MB | Pocket Nihongo pronunciation for every kana and N5 word, embedded in the app image. Generated by `tools/jp_learner/build_voice.py` with Microsoft Edge TTS (`ja-JP-NanamiNeural`, kana at -30% and words at -10% speaking rate), trimmed and peak-normalized; the pack format is documented in that script. |

The redistribution terms for the Edge TTS audio have not been confirmed. Keep `jp_voice_pack.bin` for personal study, and confirm the terms before publishing firmware or pushing the file to a public repository. When the file is absent, the firmware still builds and runs silently, and the voice-pack checks are skipped.
